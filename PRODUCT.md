# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

TypeScript, React, Vite and a local Node server, with shared DOM/SVG rendering and Chromium PDF export. This stack was reviewed in the approved implementation plan on 15/10/2026.

## Users

Visual identity designers preparing brand books for clients, including designers working through Codex and Claude Code.

## Product Purpose

Turn client identity materials and an optional structured briefing into an editorial brand manual. Open the result as editable artboards before final export. Success is a designer finishing and reopening a real client document without losing manual adjustments.

## Positioning

Marquio combines structured brand-book generation, reusable mockup direction and an editable web studio. The agents and the browser operate the same portable document.

## Operating Context

Desktop design workflow in a local browser. Designers supply logos, brand typography, copy, colors and applications as available. Missing information can be skipped. Local files are canonical; external image generation is optional and requires an available provider or imported result.

## Capabilities and Constraints

Editable text, images, shapes, groups, layers, pages and application surfaces; undo/redo; local saving and portable project; multipage PDF. No mandatory account, cloud database or paid image provider. Do not claim Photoshop depth, PSD compatibility, CMYK/PDF-X or that an exported PDF is the editable source.

## Brand Commitments

Name approved: Marquio. User explicitly requested Photoshop/PhotoCraft-like main-tool organization and a restrained black/white editorial manual. Keep all parts of the document editable. Source reference is private and does not belong in the public repository. User supplied a name that must never appear in product materials.

## Evidence on Hand

Approved design and implementation plan under `docs/`. Original legacy skill, template and PDF script remain available. Public product demonstration must use original fictitious identity assets; no customers, testimonials, metrics, external provider connection or completed generation may be invented.

## Product Principles

- A skipped section is a valid choice.
- Suggested content is identified until the designer approves it.
- The generated document is the beginning of editing.
- Save and export the same confirmed revision.
- Keep the client's identity distinct from the manual's editorial system.
