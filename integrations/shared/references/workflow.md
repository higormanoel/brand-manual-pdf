# Designer workflow

Use `node "<installed skill>/scripts/marquio.mjs"` for all commands below. Quote paths as arguments; never concatenate client text into a shell command. The launcher reads its installed repository path and executes the same canonical `bin/marquio.mjs` for both agents. Rebuild in that repository after updates. If it moves, reinstall the adapter.

1. Establish a project folder and open `studio "<folder>" --name "<brand>"`. The process prints the actual loopback URL and opens the browser. Keep the process running. Use `--demo` only for the fictitious Aurora walkthrough, never as client data.
2. Collect the optional brief in small groups: name/handle, audience, value, positioning; definitions, narratives and archetypes; voice modes, use/avoid guidance and examples; mantras/dictionary; palette, logo files/variants, typography files/weights and usage; visual descriptors/rules, content pillars, applications, designer/contributor credits. Ask only for gaps the designer wants to include. Persist each skipped section with `section.update` (`patch: {status: "skipped", enabled: false}`) and each supplied field through `project.update` or the relevant section command. Do not request skipped fields again. Source schemas: `src/core/project.ts`, `src/core/commands.ts` in the configured repository.
3. Use `validate "<folder>" --json` to obtain the latest confirmed revision, full project and real content/IDs. The checkpoint alone can be stale because later revisions live in `commits/`. Preserve real section/page/node/asset IDs. Never edit `project.marquio.json`, commits or receipts directly.
4. Import bytes using `import-asset "<folder>" "<file>" --revision N --command-id "<unique-id>"`. Consume the returned asset ID and confirmed acknowledgement revision before the next edit. Record actual provenance. Request client mockups or use the included planar templates, three original photographic scene composites, or reusable prompts. A prompt is not a generated image. Paid generation is optional and requires a user-selected available provider; otherwise import a result or use included assets.
5. Write a batch JSON file and run `apply "<folder>" --batch "<batch.json>"`. The shape is `{ "commandId": "unique-operation-id", "expectedRevision": N, "commands": [...] }`. For example, `{ "type": "project.update", "patch": { "title": "Client brand manual" } }` updates the title. Build content commands from real project IDs and schema fields. Client facts, rules, logos and credits come from the designer. Proposed copy uses `approval.status: "pending"` until explicit designer approval.
6. Run `generate "<folder>" --command-id "<unique-id>"` after the selected sections are ready. Generation appends a new variant; existing manual work remains recoverable. For an intentional replacement, use `variant.install` with `mode: "replace"` and exact `expectedPages` from the current revision. On a revision conflict reload, reconcile the change and submit a fresh command; retry the identical batch only when its outcome is unknown.
7. Open/reload the actual editable Studio using `studio "<folder>"`. Review long copy, font substitution warnings, asset provenance, layers and mockup placement with the designer. Every title, rule, credit and application remains editable. Preserve pending suggestions until approved. A browser preview must precede final PDF delivery.
8. Flush pending Studio saves and read its confirmed revision. Run `export "<folder>" --output "<manual.pdf>" --revision N`. Verify the newly produced PDF, page count, text and representative pages. Deliver that PDF together with the Studio's portable project backup. Report the exported revision and honest font/layout limitations.

Local mode saves through the repository. Browser-only mode keeps data in IndexedDB scoped to origin and port and offers portable backup and browser Print; it does not provide the local validated PDF endpoint. A new port cannot recover browser-only pending changes from another origin. Do not describe the PDF as editable source, claim PSD/CMYK/PDF-X support, invent institutional details, or imply image-provider access.
